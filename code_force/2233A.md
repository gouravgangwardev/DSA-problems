# 2233A — AI Project Development

## Question

A project contains `n` lines of code.

Maxim writes `x` lines per hour.

Nikita can either:

1. Work immediately at `y` lines per hour.
2. Spend `z` hours setting up AI, then work at `10y` lines per hour.

Maxim continues working while Nikita sets up the AI.

Find the minimum number of full hours needed to complete the project.

## Solution

### Without AI

Both programmers work immediately.

Combined speed:

`x + y`

Time required:

`T1 = ceil(n / (x + y))`

### With AI

During the `z` hours of setup, Maxim writes:

`x × z`

lines.

If:

`x × z >= n`

the project finishes during setup, so:

`T2 = z`

Otherwise, remaining work is:

`n - x × z`

After setup, the combined speed is:

`x + 10y`

Therefore:

`T2 = z + ceil((n - x × z) / (x + 10y))`

The answer is:

`min(T1, T2)`

## Complexity

- Time: `O(1)`
- Space: `O(1)`
