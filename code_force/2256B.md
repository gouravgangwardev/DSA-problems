# 2256B - Domino Tiles

**Language:** C++17

## Problem

Given a string `s` containing `0`, `1`, and `?`, replace every `?` with `0` or `1`.

For every three consecutive characters:

```text
s[i] s[i+1] s[i+2]
````

the two neighboring dominoes must have different weights.

Their weights are:

```text
s[i] + s[i+1]
s[i+1] + s[i+2]
```

Therefore:

```text
s[i] != s[i+2]
```

So every character must be different from the character two positions before it.
## Complexity

```text
Time: O(n)
Space: O(1)
```
---
## Solution 

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);

int t;
cin>>t;

while(t--){
int n;
string s;
cin>>n>>s;

long long ans=0;

for(int x=0;x<2;x++){
for(int y=0;y<2;y++){
bool ok=true;

if(s[0]!='?'&&s[0]-'0'!=x)ok=false;
if(s[1]!='?'&&s[1]-'0'!=y)ok=false;

for(int i=2;i<n&&ok;i++){
int v;

if(i%2==0)
v=x^((i/2)%2);
else
v=y^(((i-1)/2)%2);

if(s[i]!='?'&&s[i]-'0'!=v)
ok=false;
}

if(ok)ans++;
}
}

cout<<ans<<'\n';
}

return 0;
}
