# 2227C — Snowfall

## Question

Given an array of positive integers, reorder its elements so that the number of subarrays whose product is divisible by `6` is minimized.

A product is divisible by `6` if it contains both a factor `2` and a factor `3`.

## Solution

Classify every number into four groups:

1. Divisible by both `2` and `3`
2. Divisible by `2` only
3. Divisible by neither `2` nor `3`
4. Divisible by `3` only

The groups are identified using:

- `x % 6 == 0`
- `x % 2 == 0`
- `x % 3 == 0`
- otherwise

An optimal ordering is obtained by placing the groups in this order:

`Divisible by 6 → Divisible by 2 only → Neither → Divisible by 3 only`

This arrangement minimizes the number of subarrays that contain both a multiple-of-2 contribution and a multiple-of-3 contribution.

## Algorithm

For every element `x`:

- If `x % 6 == 0`, put it in group 1.
- Else if `x % 2 == 0`, put it in group 2.
- Else if `x % 3 == 0`, put it in group 4.
- Otherwise, put it in group 3.

Finally, output:

`group1 + group2 + group3 + group4`

## Complexity

- Time: `O(n)`
- Space: `O(n)`
