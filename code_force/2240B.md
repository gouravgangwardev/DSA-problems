# B. AI Finds Nothing Here

## Problem

You are given an `n × m` binary matrix.

For every `r × c` submatrix, the XOR of all its elements must be `0`.

Determine the number of matrices satisfying this condition.

The answer must be calculated modulo `998244353`.

## Key Observation

There are:

`(n-r+1) × (m-c+1)`

different `r × c` submatrices.

Each such submatrix gives one independent XOR constraint.

The matrix contains:

`n × m`

total elements.

Therefore, the number of free elements is:

`n × m - (n-r+1) × (m-c+1)`

Every free element can independently be either `0` or `1`.

Therefore, the total number of valid matrices is:

`2^(n×m-(n-r+1)×(m-c+1))`

## Formula

Let:

`free = n×m-(n-r+1)×(m-c+1)`

Then:

`answer = 2^free mod 998244353`

## Algorithm

1. Read `n`, `m`, `r`, and `c`.
2. Calculate the total number of matrix elements:

   `total = n × m`

3. Calculate the number of `r × c` submatrices:

   `constraints = (n-r+1) × (m-c+1)`

4. Calculate:

   `free = total - constraints`

5. Calculate `2^free` using binary exponentiation.
6. Take the result modulo `998244353`.
7. Print the answer.

## Example

For:

`n = 2, m = 3, r = 1, c = 2`

We have:

`total = 2 × 3 = 6`

Number of constraints:

`(2-1+1) × (3-2+1) = 2 × 2 = 4`

Therefore:

`free = 6 - 4 = 2`

So:

`answer = 2^2 = 4`

## Complexity

Binary exponentiation takes `O(log(nm))`.

- Time: `O(log(nm))`
- Space: `O(1)`

  ---
  ## Solution
 ```
#include<bits/stdc++.h>
using namespace std;
 
const long long MOD=998244353;
 
long long power(long long a,long long b){
long long res=1;
while(b){
if(b&1)res=res*a%MOD;
a=a*a%MOD;
b>>=1;
}
return res;
}
 
int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);
 
int t;
cin>>t;
 
while(t--){
long long n,m,r,c;
cin>>n>>m>>r>>c;
 
long long total=n*m;
long long constraints=(n-r+1)*(m-c+1);
long long free=total-constraints;
 
cout<<power(2,free)<<'\n';
}
 
return 0;
}
```
