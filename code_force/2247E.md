# E. Build a Tree

## Question

Given `n` vertices and a target value `k`, construct a tree such that

$$
\sum_{i=1}^{n} dist(i,(i\bmod n)+1)=k
$$

or print `-1` if it is impossible.

The vertices are labeled `1...n`, and the required distances are between consecutive vertices in the cyclic order:

```text
1-2, 2-3, ..., (n-1)-n, n-1
```

### Complexity

```text
Time:  O(n)
Space: O(n)
```

The total `n` over all test cases is at most `2 × 10^5`. ([Codeforces][1])

## C++ Code

```cpp
#include<bits/stdc++.h>
using namespace std;

using ll=long long;

void build(vector<int>&v,ll need){
    int m=v.size();

    if(!m)return;

    int len=1;

    while(len<m&&(ll)len*(len+1)/2<=need)
        len++;

    len--;

    for(int i=0;i<len;i++){
        if(i==0)cout<<v[i]<<" 1\n";
        else cout<<v[i]<<" "<<v[i-1]<<"\n";
    }

    if(len<m){
        ll rem=need-(ll)len*(len-1)/2;

        if(rem==0)
            cout<<v[len]<<" 1\n";
        else
            cout<<v[len]<<" "<<v[rem-1]<<"\n";

        for(int i=len+1;i<m;i++)
            cout<<v[i]<<" 1\n";
    }
}

void solve(){
    int n;
    ll k;
    cin>>n>>k;

    if(k<2LL*(n-1)||k%2){
        cout<<-1<<"\n";
        return;
    }

    ll e=n/2;
    ll o=(n-1)/2;

    ll mx=e*(e-1)/2+o*(o-1)/2;
    ll need=(k-2LL*(n-1))/2;

    if(need>mx){
        cout<<-1<<"\n";
        return;
    }

    ll even=min(need,e*(e-1)/2);
    ll odd=need-even;

    vector<int>ev,od;

    for(int i=2;i<=n;i+=2)
        ev.push_back(i);

    for(int i=3;i<=n;i+=2)
        od.push_back(i);

    build(ev,even);
    build(od,odd);
}

int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin>>t;

    while(t--)
        solve();
}
```
