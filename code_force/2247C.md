# C. Inversion of a Subsequence

## Question

You are given two binary arrays `a` and `b` of length `n`.

In one operation, choose any non-empty subsequence of `a` whose sum is odd, and invert every selected element:

`0 → 1`

`1 → 0`

Find the minimum number of operations required to transform `a` into `b`, or output `-1` if it is impossible.

## Solution

Let:

- `ca` = number of `1`s in `a`
- `cb` = number of `1`s in `b`

### Case 1: Arrays are already equal

If:

`a == b`

then no operation is required.

Answer:

`0`

### Case 2: `a` contains no `1`

If `a` consists entirely of zeros, no valid operation can be performed because every selected subsequence would have sum `0`, which is not odd.

Therefore, if `a != b`:

`ca == 0 → -1`

### Case 3: `b` consists entirely of `1`s

To transform `a` into an all-ones array, every zero must be flipped.

However, the required transformation is impossible under the operation constraint in this case.

Therefore:

`cb == n → -1`

### Case 4: One operation is enough

A single operation can transform `a` into `b` when the number of `1`s that need to be changed from `1 → 0` is odd.

Let `d` be the number of positions where:

`a[i] = 1` and `b[i] = 0`

If:

`d % 2 == 1`

then the required subsequence has odd sum, so:

`answer = 1`

### Case 5: Two operations

For all remaining possible transformations, two valid operations are sufficient.

Therefore:

`answer = 2`

## Algorithm

1. Read arrays `a` and `b`.
2. Count the number of `1`s in both arrays.
3. If `a == b`, print `0`.
4. If `a` has no `1`s, print `-1`.
5. If `b` contains only `1`s, print `-1`.
6. Count positions where `a[i] = 1` and `b[i] = 0`.
7. If this count is odd, print `1`.
8. Otherwise, print `2`.

## Complexity

- Time: `O(n)`
- Space: `O(n)`
