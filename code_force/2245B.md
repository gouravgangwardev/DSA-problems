
# Delete and Concatenate
## Problem

Given an array `a` and operation cost `c`:

- Remove one element and gain its value.
- Remove two adjacent elements and gain their maximum.
- Every operation costs `c`.
- Maximize the final score.

## Key Observation

Taking `x` and `y` separately gives:

```text
x + y - 2c
````

Taking them together gives:

```text
max(x,y) - c
```

Gain from pairing:

```text
c - min(x,y)
```

So pairing is useful when:

```text
min(x,y) < c
```

## Complexity

```text
Time: O(n log n)
Space: O(n)
```

---

## Solution 
```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);

int t;
cin>>t;

while(t--){
int n;
long long c;
cin>>n>>c;

vector<long long>a(n);
long long sum=0;

for(auto&x:a){
cin>>x;
sum+=x;
}

sort(a.begin(),a.end());

long long ans=sum-1LL*n*c;
int l=0,r=n-1;

while(l<r&&a[l]<c){
ans+=c-a[l];
l++;
r--;
}

cout<<ans<<'\n';
}

return 0;
}
```
