# C. RemovevomeR

## Problem

You are given a binary string `s`.

In one operation, you can choose a palindromic substring of length at least `2` and delete exactly one character from it.

Determine the minimum possible length of the string after performing the operation any number of times.

## Key Observation

A binary string has a palindromic substring of length at least `2` if and only if it contains two equal adjacent characters.

For example:

`00` and `11` are both palindromes.

Therefore, first check whether:

`s[i] == s[i-1]`

for any adjacent pair.

### Case 1: No equal adjacent characters

The string is alternating:

`010101...`

or

`101010...`

No palindromic substring of length at least `2` exists.

Therefore no operation can be performed.

Answer:

`n`

### Case 2: Equal adjacent characters exist

Once a palindrome exists, characters can be repeatedly deleted.

For `n >= 4`, the string can always be reduced to a single character.

Therefore:

`answer = 1`

For `n <= 3`, the minimum is `2`.

## Algorithm

1. Check whether the string contains two equal adjacent characters.
2. If no such pair exists, print `n`.
3. Otherwise:
   - If `n <= 3`, print `2`.
   - Otherwise, print `1`.

## Example

For:

`0000`

There are equal adjacent characters.

The string can be reduced:

`0000 -> 000 -> 00 -> 0`

Answer:

`1`

For:

`110`

We have:

`11`

which is a palindrome.

We can perform:

`110 -> 10`

Now `10` contains no palindromic substring of length at least `2`.

Answer:

`2`

For:

`1010`

There are no equal adjacent characters.

No operation is possible.

Answer:

`4`

## Complexity

- Time: `O(n)`
- Space: `O(1)`

---

## Solution 
```
#include<bits/stdc++.h>
using namespace std;

int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);

int t;
cin>>t;

while(t--){
int n;
string s;
cin>>n>>s;

int runs=1;

for(int i=1;i<n;i++){
if(s[i]!=s[i-1])runs++;
}

if(runs==2)
cout<<2<<'\n';
else
cout<<1<<'\n';
}

return 0;
}
```
