# 2236A — Games on the Train

## Question

Given `n` tower heights, increase every tower by an integer `xi` such that:

1 ≤ xi ≤ k

After increasing all towers, their heights must be equal.

Find the minimum possible value of `k`.

## Solution

Let:

- `mx` = maximum tower height
- `mn` = minimum tower height

Since every tower must be increased by at least `1`, the final height must be at least:

`mx + 1`

The tower with minimum height needs the largest increase:

`(mx + 1) - mn`

Therefore:

`answer = mx - mn + 1`

## Complexity

- Time: `O(n)`
- Space: `O(1)`
