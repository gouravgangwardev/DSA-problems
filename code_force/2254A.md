# A. Riptide

## Approach

The game ends immediately if any two players have the same number of tokens.

Otherwise, in every round:

1. Find the player with the minimum number of tokens.
2. Find the player with the maximum number of tokens.
3. The maximum player gives one token to the minimum player.
4. Increase the answer by `1`.
5. Repeat until two token counts become equal.

The minimum and maximum indices must be determined before modifying the values.

## Algorithm

For each test case:

* Store the three token counts in an array.
* While all three values are different:

  * Find the indices of the minimum and maximum values.
  * Increment the minimum value.
  * Decrement the maximum value.
  * Increment the round count.
* Output the number of rounds.

## Example

For:

```text
1 7 10
```

The game proceeds as:

```text
1 7 10
2 7 9
3 7 8
4 7 7
```

Two players now have the same number of tokens, so the game ends after `3` rounds.

## C++ Solution

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin>>t;

    while(t--){
        int a[3],ans=0;
        cin>>a[0]>>a[1]>>a[2];

        while(a[0]!=a[1]&&a[1]!=a[2]&&a[0]!=a[2]){
            int mn=0,mx=0;

            for(int i=1;i<3;i++){
                if(a[i]<a[mn])mn=i;
                if(a[i]>a[mx])mx=i;
            }

            a[mn]++;
            a[mx]--;
            ans++;
        }

        cout<<ans<<'\n';
    }
}
```

## Complexity

For each test case:

* **Time Complexity:** `O(R)`, where `R` is the number of rounds.
* **Space Complexity:** `O(1)`.

Since `a`, `b`, and `c` are at most `10`, the number of rounds is very small.
