# A. Three Numbers on the Blackboard

## Approach

For three numbers, sort them:

```text id="a1b2c3"
x <= y <= z
```

Initially, the range is:

```text id="d4e5f6"
z - x
```

The useful operation is to replace the largest number `z` with the sum of the other two:

```text id="g7h8i9"
z = x + y
```

The new numbers become:

```text id="j1k2l3"
x, y, x + y
```

Their range is:

```text id="m4n5o6"
(x + y) - x = y
```

Therefore, the minimum possible range is:

```text id="p7q8r9"
min(z - x, y)
```

## Algorithm

For each test case:

1. Read `a`, `b`, and `c`.
2. Sort the three numbers.
3. Let the sorted values be `x <= y <= z`.
4. Output:

```text id="s1t2u3"
min(z - x, y)
```

## Example

For:

```text id="v4w5x6"
2 3 10
```

After sorting:

```text id="y7z8a9"
2 3 10
```

Original range:

```text id="b1c2d3"
10 - 2 = 8
```

Replace `10` with:

```text id="e4f5g6"
2 + 3 = 5
```

The numbers become:

```text id="h7i8j9"
2 3 5
```

New range:

```text id="k1l2m3"
5 - 2 = 3
```

So the answer is:

```text id="n4o5p6"
min(8,3) = 3
```

## C++ Solution

```cpp id="q7r8s9"
#include<bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin>>t;

    while(t--){
        long long a,b,c;
        cin>>a>>b>>c;

        vector<long long>v={a,b,c};
        sort(v.begin(),v.end());

        cout<<min(v[2]-v[0],v[1])<<'\n';
    }
}
```

## Complexity

```text id="t1u2v3"
Time Complexity: O(1) per test case
Space Complexity: O(1)
```
