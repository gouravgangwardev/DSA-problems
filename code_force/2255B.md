# B. A Ribbon for Tomorrow

## Problem

You are given a binary string `s` of length `n`.

You can perform the following operation any number of times:

* Choose two indices `l` and `r` such that `s[l] == s[r]`.
* Reverse the substring from `l` to `r`.

The task is to determine how many distinct binary strings can be obtained after performing these operations any number of times.

The answer is required modulo:

```text
998244353
```

---



```text
answer = 3 × 1 = 3
```

The reachable strings are:

```text
001010
010010
010100
```

---

## C++ Solution

```cpp
#include<bits/stdc++.h>
using namespace std;

const int mod=998244353,N=1000005;
long long f[N],inv[N];

long long power(long long a,long long b){
    long long r=1;
    while(b){
        if(b&1)r=r*a%mod;
        a=a*a%mod;
        b>>=1;
    }
    return r;
}

long long C(int n,int r){
    if(r<0||r>n)return 0;
    return f[n]*inv[r]%mod*inv[n-r]%mod;
}

int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);

    f[0]=1;
    for(int i=1;i<N;i++)f[i]=f[i-1]*i%mod;
    inv[N-1]=power(f[N-1],mod-2);
    for(int i=N-2;i>=0;i--)inv[i]=inv[i+1]*(i+1)%mod;

    int t;
    cin>>t;

    while(t--){
        int n,z=0,o=0,c=0;
        string s;
        cin>>n>>s;

        for(int i=0;i<n;i++){
            if(s[i]=='0')z++;
            else o++;
            if(i&&s[i]!=s[i-1])c++;
        }

        int zr,orun;

        if(s[0]=='0'){
            zr=(c+2)/2;
            orun=(c+1)/2;
        }else{
            orun=(c+2)/2;
            zr=(c+1)/2;
        }

        long long ans=1;

        if(z)ans=ans*C(z-1,zr-1)%mod;
        if(o)ans=ans*C(o-1,orun-1)%mod;

        cout<<ans<<'\n';
    }
}
```
