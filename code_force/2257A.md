# 2257A - Creating Abbreviations

**Language:** C++17

## Problem

Given `n` initial words and `m` abbreviations, determine whether there exists an order in which all abbreviations can be created.

An abbreviation is formed using the first letters of one or more available words. Newly created abbreviations can also be used as words in later operations.

## Key Observation

Only the **first character** of every available word matters.

Initially, store the first letters of all ordinary words.

For every abbreviation:

- If every character of the abbreviation is currently available, it can be created.
- After creating it, its first character becomes available as well.
- Repeat until no more abbreviations can be created.

If all `m` abbreviations are created, print `YES`; otherwise print `NO`.

The same word can be used multiple times, so a single available letter can be used repeatedly.

## Complexity

```text
Time: O(m² × L)
Space: O(26 + m)

---

## Solution 
```
#include<bits/stdc++.h>
using namespace std;
 
int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);
 
int t;
cin>>t;
 
while(t--){
int n,m;
cin>>n>>m;
 
set<char>have;
vector<string>a(m);
 
for(int i=0;i<n;i++){
string s;
cin>>s;
have.insert(s[0]-'a'+'A');
}
 
for(auto&x:a)cin>>x;
 
vector<bool>done(m);
int cnt=0;
 
while(1){
bool changed=false;
 
for(int i=0;i<m;i++){
if(done[i])continue;
 
bool ok=true;
 
for(char c:a[i]){
if(!have.count(c)){
ok=false;
break;
}
}
 
if(ok){
done[i]=true;
cnt++;
have.insert(a[i][0]);
changed=true;
}
}
 
if(!changed)break;
}
 
cout<<(cnt==m?"YES":"NO")<<'\n';
}
 
return 0;
}
