# Another Popcount Problem

## Problem

Given two integers `n` and `k`, construct a sequence of `k` non-negative integers such that:

`a1 + a2 + ... + ak <= n`

The goal is to maximize:

`popcount(a1) + popcount(a2) + ... + popcount(ak)`

where `popcount(x)` is the number of set bits in the binary representation of `x`.

Only the maximum possible total popcount needs to be printed.

## Key Observation

To increase the popcount of a number, we need to add another set bit.

The cheapest number with exactly `p` set bits is:

`1 + 2 + 4 + ... + 2^(p-1)`

Therefore the costs of adding consecutive set bits are:

```text
1, 2, 4, 8, 16, ...
```
---

## Solution
```
#include<bits/stdc++.h>
using namespace std;
 
int main(){
ios::sync_with_stdio(false);
cin.tie(nullptr);
 
int t;
cin>>t;
 
while(t--){
long long n,k;
cin>>n>>k;
 
long long ans=0;
long long cost=1;
 
while(n>=cost){
long long cnt=min(k,n/cost);
ans+=cnt;
n-=cnt*cost;
cost*=2;
}
 
cout<<ans<<'\n';
}
 
return 0;
}

```
