# B. Bermuda Rectangle

## Question

The Bermuda Rectangle has area `S`, integer side lengths, and its bottom-left corner is at `(0,0)`.

For a query `(x,y)`, consider an `x × y` rectangle whose bottom-left corner is also `(0,0)`. Count how many cells of this rectangle can belong to at least one possible Bermuda Rectangle.

### Input

* `t` test cases.
* For each test case:

  * `S` and `q`
  * `q` queries `(x,y)`

Constraints:

* `1 ≤ S ≤ 10^14`
* `1 ≤ q ≤ 3 × 10^5`
* Sum of `√S` over all test cases ≤ `10^7`.

### Output

For every query, output the number of cells that can be covered.

---

## Answer

For a Bermuda Rectangle with width `d`:

```text
height = S / d
```

Therefore, `d` must be a divisor of `S`.

For every column, the maximum possible height is determined by the smallest divisor of `S` that is greater than the column index. This forms a staircase.

Generate and sort all divisors of `S`, then precompute prefix sums for the staircase. Each query can then be answered using binary search.

### C++ Code

```cpp
#include<bits/stdc++.h>
using namespace std;

using ll=long long;

int main(){
    ios::sync_with_stdio(0);
    cin.tie(0);

    int t;
    cin>>t;

    while(t--){
        ll S;
        int q;
        cin>>S>>q;

        vector<ll>d;

        for(ll i=1;i*i<=S;i++){
            if(S%i==0){
                d.push_back(i);
                if(i*i!=S)d.push_back(S/i);
            }
        }

        sort(d.begin(),d.end());

        int m=d.size();
        vector<ll>sum(m+1),area(m+1);

        ll prev=0;

        for(int i=0;i<m;i++){
            ll len=d[i]-prev;
            sum[i+1]=sum[i]+len;
            area[i+1]=area[i]+len*(S/d[i]);
            prev=d[i];
        }

        while(q--){
            ll x,y;
            cin>>x>>y;

            int k=lower_bound(d.begin(),d.end(),x)-d.begin();
            int p=upper_bound(d.begin(),d.end(),S/y)-d.begin();

            ll ans=0;
            int full=min(k,p);

            ans+=sum[full]*y;
            ans+=area[k]-area[full];

            ll prev=k?d[k-1]:0;
            ans+=(x-prev)*min(y,S/d[k]);

            cout<<ans<<'\n';
        }
    }
}
```
